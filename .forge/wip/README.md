Scaffolding of work in flight: `plan.md`, `changes.md` and `review.md`, in
a folder per spec.

It lives here so a teammate who checks out your branch sees exactly where
you left off. `forge archive` deletes it in the last commit of the pull
request, so the main branch only accumulates what stays useful.

Nothing is lost when it is deleted: it remains in the history of that
branch.
